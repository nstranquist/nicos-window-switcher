# Security

Nicos Window Switcher is a local macOS app. It uses public Accessibility and
Carbon hotkey APIs only. It does not send telemetry and it does not require
an account.

Do not attach live `~/.config/nicos-window-switcher/config.json` with personal
window titles, or Screen Recording captures of other people's screens, to
issues or pull requests.

Please do not disclose security issues in a public issue.

Use GitHub's private vulnerability reporting for this repository. If it is
unavailable, contact [@nstranquist](https://github.com/nstranquist) privately
before public disclosure.
